title: "Pinned resources"
description: "Keep the links your team opens every day, such as folders, guidelines and dashboards, one click away."
---

Resources is a short list of pinned links. Use it for the things people keep asking about: the shared drive folder, the brand guidelines, the analytics dashboard, the staging site. Each link opens in a new tab.

A link has a title and a web address. You can also add a short description and an emoji, which Kaneo shows beside the title instead of the default link icon.

## Where resources appear

| Place | What it shows | Who sees it |
| --- | --- | --- |
| **Resources** in the sidebar | The workspace's full list, where you add, edit, reorder and remove links | Everyone in the workspace |
| **Pinned resources** on Home | The first six links of the workspace list as tiles | Everyone in the workspace |
| **Resources** tab in a project | Links for that project only | People who can open the project |

The workspace list is for links the whole team shares. The project list is for links that only matter to one project, so they do not crowd the workspace list.

## Add a link

1. Open **Resources** in the sidebar, or the **Resources** tab inside a project.
2. Choose **Add link**.
3. Enter a title and the address. An address without `https://`, such as `drive.google.com/…`, is accepted and gets it added for you. Only `http://` and `https://` addresses can be pinned.
4. Optionally add a description and an emoji, then choose **Add link**.

Open the menu on a link to edit or remove it. Removing a link unpins it for everyone and does not touch the page it points to. Drag a link by its handle to change the order. The order is the same for everyone and is also what Home shows.

A list holds up to 100 links.

## Who can change them

Everyone who can see a list can open its links. Changing a list needs more:

| List | Needed to add, edit, reorder or remove |
| --- | --- |
| Workspace | Permission to manage workspace settings. Owners and admins have it by default. |
| Project | Permission to update the project. Owners and admins have it by default. |

Members and viewers see the list without the add button or the edit menu. If your workspace uses [custom roles](/core/functional/collaborate-with-team), the same two permissions decide who can change the lists.

When a project is moved to another workspace, its links move with it.

## Good to know

- Resources does not update live. Other people's changes appear after you reload the page or return to the tab.
- Links are not checked. If the page behind a link moves, edit the link.
- Anyone who can see a list can read its addresses. Do not pin a link that contains a token or secret in its address.
